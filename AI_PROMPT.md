# Промпт для нейросети

Скопируйте всё, что ниже линии, в ChatGPT / Claude / Gemini, допишите свой текст — и вставьте ответ в SpeakerNotes (кнопка 📥 «Вставить»).
Тот же промпт копируется кнопкой «Скопировать промпт» прямо в приложении.

---

````text
Ты помогаешь оформлять фразы и шпаргалки для приложения SpeakerNotes (бесконечная доска с карточками для оператора колл-центра / консультанта).
Твоя задача: взять мой текст (или файл) и превратить его в короткие, готовые к произношению фразы для ответа клиентам, сгруппированные по темам, и выдать результат СТРОГО в формате «SpeakerNotes Markup», описанном ниже.

ГЛАВНЫЕ ПРАВИЛА
1. Выдай ответ ОДНИМ блоком кода (\`\`\`text … \`\`\`), без пояснений до и после — я скопирую его целиком.
2. Каждая строка-команда начинается с @ в самом начале строки.
3. Одна карточка = одна законченная фраза, которую можно сказать клиенту. Карточки разделяй пустой строкой.
4. Группируй всё по темам: каждая тема — отдельный раздел @frame. Темы называй коротко и понятно (2–4 слова), можно с эмодзи в начале.
5. Внутри раздела используй заголовки (#, ##) для подтем.
6. Не выдумывай факты (цены, тарифы, сроки). Если данных нет — оставь поле для подстановки в квадратных скобках: [сумма], [дата], [имя].
7. Язык фраз — тот же, что в исходном тексте, если я не попросил иначе.

КОМАНДЫ
@board Название доски          — (необязательно, в самом начале) создать отдельную доску
@frame Название | color: green | tags: тег1, тег2   — начать раздел (тему). Цвета: red, orange, yellow, green, teal, blue, purple, pink, gray
@endframe                       — закончить раздел (необязательно: следующий @frame закроет предыдущий)
# Большой заголовок
## Заголовок
### Подзаголовок
Обычная строка текста          — фраза-карточка (несколько строк подряд без пустой строки = одна карточка)
- пункт                         — каждый пункт списка становится ОТДЕЛЬНОЙ карточкой
@note Текст                     — явная карточка (внутри можно делать списки "- " и "1. ", они останутся в одной карточке)
@tip Текст                      — плашка-подсказка 💡
@info Текст                     — плашка-информация ℹ️
@warn Текст   (или строка "! Текст")   — плашка «Важно» ⚠️
@danger Текст (или строка "!! Текст")  — плашка «Нельзя / запрещено» ⛔
@success Текст                  — плашка «Можно / хорошо» ✅
@table … @end                   — таблица в формате Markdown между @table и @end (первая строка — заголовки)
@dialog … @end                  — пример диалога; каждая строка начинается с "Клиент:" или "Я:"
@checklist Название … @end      — чек-лист / шаги; строки вида "[ ] шаг" или "[x] шаг"
@image Подпись                  — место для картинки/скриншота (я вставлю картинку сам)
@link A -> B "подпись"          — стрелка от карточки A к карточке B (A и B — ключи карточек или точные названия разделов/заголовков)
       стрелки: ->  обычная,  <->  в обе стороны,  --  линия без стрелки; в конце можно добавить | style: dashed | color: red

СВОЙСТВА КАРТОЧКИ — в конце строки в фигурных скобках:
Текст фразы {key: privet, color: green, fav}
  key   — короткий латинский ключ, чтобы ссылаться на карточку в @link
  color — цвет карточки
  fav   — добавить в избранное (самые частые фразы)

ФОРМАТИРОВАНИЕ ВНУТРИ ТЕКСТА
**жирный**   *курсив*   __подчёркнутый__   ~~зачёркнутый~~   ==выделение маркером==
{red: красный текст}  (также orange, yellow, green, teal, blue, purple, pink, gray)
[имя клиента]   — поле для подстановки (подсвечивается)
[[Название раздела]]   — ссылка-переход на раздел или заголовок
\`код или номер\`
````
