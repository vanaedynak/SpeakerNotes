# SpeakerNotes

**Бесконечная доска для фраз, скриптов и шпаргалок** — чтобы во время разговора с клиентом за секунду найти нужную фразу и скопировать её.

Работает везде: **iPad / iPhone, Android, Windows, macOS, Linux** и просто в браузере.

| iPad (без установки) | [веб-версия](https://vanaedynak.github.io/SpeakerNotes/) | Открыть в Safari → «Поделиться» → «На экран Домой». Работает офлайн |
| Android | `SpeakerNotes-android.apk` | Открыть файл на телефоне, разрешить установку из этого источника |
| Windows | `SpeakerNotes-Windows-portable.exe` | Запускается без установки (или `-setup.exe` — установщик) |
| macOS | `SpeakerNotes-macOS.dmg` | При первом запуске: правый клик → «Открыть» |
| Linux | `SpeakerNotes-Linux.AppImage` | `chmod +x` и запустить |

Сборки делает GitHub Actions автоматически при каждом изменении в ветке `main`.

## Что умеет

- 🌊 **Бесконечная доска** — двигайте пальцем, масштабируйте щипком / Ctrl+колесо. Двойной тап по пустому месту — новая фраза.
- ▢ **Разделы (рамки)** — группируют фразы по темам; при отдалении показываются крупные названия, тап по названию — перелёт к разделу.
- ⚡ **Быстрый режим** — для звонка: слева темы, справа фразы крупным текстом; **тап = скопировано**. Есть «★ Избранное» и «🕘 Недавние».
- 🔍 **Поиск по всем доскам** (Ctrl+K) — понимает неправильную раскладку (`ghbdtn` → «привет»), ё/е, одну опечатку, ищет по тегам и названиям разделов.
- ☰ **Содержание** — список разделов и заголовков доски, фильтр и теги.
- Элементы: 💬 фраза, 🔠 заголовок, ⚠️ плашки (важно / нельзя / подсказка / инфо / можно), ▦ таблица, 🗨 диалог «Клиент — Я», ☑ чек-лист, 🖼 картинка.
- ✂️ **Стикеры из скриншотов** — обрезка прямоугольником, кругом или **обводкой пальцем**, белая обводка как у стикера.
- ↗ **Стрелки-связи** с подписями (обычные, пунктир, двусторонние, цветные) и **ссылки-переходы** `[[Название раздела]]`.
- Форматирование: **жирный**, *курсив*, подчёркнутый, зачёркнутый, ==маркер==, цветной текст, `[поле для подстановки]`, списки.
- 📖 **Режим чтения** — ничего случайно не сдвинется, тап по фразе копирует её.
- 👓 **Для слабого зрения** — темы «Чёрная» (белый на чёрном), «Контраст» (жёлтый на чёрном), тёмная, светлая, сепия; размер текста до 240 %, шрифт Atkinson Hyperlegible, жирный текст, межстрочный интервал, «Показать крупно».
- 💾 Всё хранится локально на устройстве; резервная копия в `.json` (Настройки → Данные) для переноса между устройствами.

## Нейросети → SpeakerNotes

В приложении: **📥 Вставить → «Скопировать промпт»**. Вставьте промпт в ChatGPT / Claude / Gemini, добавьте свой текст или файл — нейросеть вернёт текст в формате *SpeakerNotes Markup*. Скопируйте ответ и вставьте в то же окно (или просто Ctrl+V на доске) — появятся разделы, заголовки, таблицы, диалоги и стрелки.

Промпт целиком: [AI_PROMPT.md](AI_PROMPT.md). Кратко о формате:

```text
@frame 😡 Недовольный клиент | color: red | tags: жалобы
# Успокоить
Я понимаю, насколько это неприятно. Давайте разберёмся. {key: calm, fav}
!! Не перебивать клиента.
@table
| Тариф | Цена |
| --- | --- |
| [название] | [цена] |
@end
@dialog
Клиент: Верните деньги!
Я: Понимаю вас, давайте проверим.
@end
@endframe
@link calm -> Тарифы "если спросит про цену"
```

## Разработка

```bash
npm install
npm run dev          # http://localhost:5180
npm run build        # веб-сборка в dist/
npm run electron     # запустить десктоп-версию
npm run icons        # перегенерировать иконки из SVG
```

Стек: React + TypeScript + Vite, Zustand, IndexedDB; Capacitor (iOS/Android), Electron (десктоп).
